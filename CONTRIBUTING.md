# Contributing to Badgeyay

Thank you for your interest in contributing to Badgeyay 🎉  
We welcome contributions from developers of all experience levels.

---

## Getting Started

Before contributing, please make sure you have set up the project locally by following the installation guides for the frontend and backend.

---

## How to Contribute

1. Fork the repository
2. Create a new branch from `development`
3. Make your changes
4. Commit your work with clear commit messages
5. Open a Pull Request to the `development` branch

---

## Pull Request Guidelines

- Write clear and meaningful commit messages
- Reference related issues in your PR description (e.g., `Closes #123`)
- Add screenshots or GIFs for UI-related changes
- Ensure all tests and checks pass before requesting a review
- Keep PRs focused and limited to a single issue when possible

---

## Branch Policy

- `development` – active development and incoming contributions
- `master` – stable releases

---

## Communication

If you need help or want to discuss an issue:
